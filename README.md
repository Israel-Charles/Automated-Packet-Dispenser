# Automated-Packet-Dispenser
Automated packet dispenser programmed using the Arduino microcontroller, digital sensors and electromechanical actuators. Designed the control logic to initiate a full dispensing cycle via a digital touch sensor, 180° servo motion for packet pushing, and a timed 10-second operation of a 5V gear motor for packet transport
